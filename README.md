# Мафия AI (`qwen2.5:7b`)

Минималистичная браузерная настольная игра **«Мафия»** для 1 игрока-человека против 6 ИИ-соперников на локальной модели **Ollama (`qwen2.5:7b`)**.

## Особенности
- **Выбор модели ИИ в лобби:** перед началом партии автоматически подтягивается список всех установленных в `ollama list` моделей (например, `qwen2.5:7b`, `gemma3:4b`, `mistral:7b`, `qwen2.5:3b`, `qwen2.5:1.5b`) с указанием объёма и возможностью обновить список в один клик.
- **7 игроков за столом:** 2 Мафии и 5 Мирных жителей (роли, места и очерёдность распределяются случайно).
- **Игра в закрытую:** роли убитых ночью и казнённых днём не раскрываются ведущим до самого финала партии.
- **Честное незнание ролей:** сервер физически изолирует контекст — мирные ИИ не получают в промпт чужих ролей, а мафия знает только своего единственного напарника и приватный ночной чат.
- **Случайные личности в каждой партии:** у каждого из 6 ИИ свой пол (`М`/`Ж`), имя и уникальный характер (12 архетипов: *Холодный аналитик*, *Напористый обвинитель*, *Подозрительный параноик*, *Осторожный тихоня*, *Ироничный скептик* и др.).
- **Только русский язык и ролевой контекст:** JSON-разделение скрытой мысли (`thought`) и речи вслух (`speech`) + серверная фильтрация от иероглифов, латиницы и выхода из роли.
- **Разбор полётов в финале:** по окончании партии открываются все роли, характеры ИИ, ночные переговоры мафии и скрытые мысли ИИ к каждой реплике.

## Быстрый запуск (localhost)

1. Убедитесь, что запущен локальный сервер **Ollama** и скачана модель `qwen2.5:7b`:
   ```bash
   ollama serve
   # В другом окне (если модель ещё не скачана):
   ollama pull qwen2.5:7b
   ```

2. Установите зависимости в виртуальное окружение (если ещё не установлены):
   ```bash
   python3 -m venv .venv
   .venv/bin/pip install -r requirements.txt
   ```

3. Запустите сервер игры (работает строго на `127.0.0.1:8000`):
   ```bash
   .venv/bin/python run.py
   ```

4. Откройте в браузере: **http://127.0.0.1:8000**
